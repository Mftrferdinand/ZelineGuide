Apa itu Zeline?

Zeline adalah framework Agentic AI open-source yang dikembangkan oleh Zerolinear. Berbeda dari chatbot biasa yang hanya menjawab pertanyaan, Zeline dirancang untuk memahami tujuan, menggunakan tools, menjalankan perintah, mengelola file, dan menyelesaikan tugas secara bertahap.

Persistent Memory

Menyimpan informasi dan konteks untuk penggunaan berikutnya.

Lightweight Agent

Bisa dijalankan melalui terminal Android (Termux), Linux, macOS, maupun Windows.

Built-in Tools

Mendukung pencarian web, pengelolaan file, eksekusi kode, dan berbagai tools lainnya.

Skills & Self-Improvement

Mendukung prosedur reusable serta mekanisme evaluasi dan penyempurnaan skill yang terkontrol.

Multi-Platform

Bisa dihubungkan dengan Telegram, WhatsApp, dan HTTP webhook.

Model Agnostic

Tidak bergantung pada satu model AI. Bisa menggunakan berbagai provider atau API yang kompatibel.

Zeline bersifat open-source, sehingga siapa pun bisa mempelajari, menggunakan, dan mengembangkannya. Kode sumber: github.com/Mftrferdinand/Zeline

1

Install Termux

Untuk pengguna Android, Zeline dijalankan menggunakan aplikasi Termux.

Download Termux melalui salah satu sumber resmi berikut:

F-Droidf-droid.org/packages/com.termux
GitHub Releasesgithub.com/termux/termux-app/releases

Setelah terpasang, buka Termux dan jalankan:

TERMUX
pkg update && pkg upgrade -y

Kemudian install kebutuhan dasar:

TERMUX
pkg install curl git python nodejs-lts -y
2

Install Zeline

Satu perintah untuk mengunduh dan menjalankan installer resmi v0.4.5.

Jalankan perintah berikut di Termux:

TERMUX — INSTALLER
curl -fsSLO --proto '=https' --tlsv1.2 https://github.com/Mftrferdinand/Zeline/releases/download/v0.4.5/install.sh && bash install.sh

Setelah instalasi selesai, periksa versi:

TERMUX
zeline version

Kemudian jalankan konfigurasi:

TERMUX
zeline setup

Ikuti instruksi yang muncul pada terminal.

3

Install 9Router Opsional

Lewati langkah ini kalau kamu sudah punya API key dari provider lain.

Apa itu 9Router?

9Router adalah layanan router API yang memungkinkan kita menghubungkan berbagai provider dan model AI melalui satu endpoint. 9Router bersifat opsional — jika sudah memiliki API key dari provider lain, Zeline dapat langsung digunakan tanpa 9Router.

Untuk mencoba 9Router, jalankan:

TERMINAL
npm install -g 9router

Kemudian:

TERMINAL
9router

Catatan kompatibilitas: Instalasi 9Router secara native di Termux belum dijamin kompatibel. Dokumentasi resminya mengutamakan Linux, macOS, dan Windows. Jika gagal pada Android, gunakan 9Router di komputer atau VPS, atau sambungkan Zeline langsung ke provider API.

Jika 9Router berhasil dijalankan, buka browser:

http://localhost:20128

Konfigurasi 9Router

  1. Login ke dashboard dan ganti password default.
  2. Buka menu Providers.
  3. Pilih provider AI yang ingin digunakan.
  4. Hubungkan akun atau API key sesuai petunjuk provider.
  5. Masuk ke Settings → API Keys.
  6. Salin API key 9Router.

Pastikan provider sudah terhubung dan model tersedia sebelum melanjutkan.

4

Hubungkan Model AI ke Zeline

Atur provider, base URL, dan API key yang akan dipakai Zeline.

Kembali ke terminal dan jalankan:

TERMUX
zeline model

Pada konfigurasi model, pilih provider API yang kompatibel dengan OpenAI. Jika menggunakan 9Router yang berjalan di perangkat yang sama, masukkan:

http://127.0.0.1:20128/v1
API key dari dashboard 9Router

Kemudian pilih model dari daftar yang berhasil terdeteksi.

Jika 9Router dijalankan di VPS atau perangkat lain, gunakan URL endpoint server tersebut, bukan localhost. Setelah selesai, Zeline akan menggunakan model yang sudah dikonfigurasi.

5

Hubungkan Zeline ke Telegram

Buat bot Telegram agar Zeline bisa digunakan langsung melalui chat.

1 — Buat bot Telegram

  • Buka t.me/BotFather
  • Kirim perintah /newbot
  • Masukkan nama bot.
  • Tentukan username bot (harus diakhiri “bot”).
  • Salin Bot Token yang diberikan BotFather.

2 — Konfigurasi Telegram di Zeline

Kembali ke Termux:

TERMUX
zeline gateway setup telegram

Masukkan Bot Token, kemudian ikuti konfigurasi owner dan akses yang tersedia.

Jangan bagikan Bot Token kepada siapa pun. Siapa pun yang memegang token ini dapat mengendalikan bot kamu.

3 — Jalankan Gateway

TERMUX
zeline gateway start

Periksa status:

TERMUX
zeline gateway status

4 — Mulai chatting

Buka bot Telegram yang sudah dibuat, lalu kirim:

TELEGRAM
/start

Coba kirim pesan:

Halo Zeline, perkenalkan dirimu dan jelaskan tools yang tersedia.

Jika bot membalas, berarti Zeline berhasil terhubung! 🎉

Step 6 — Perintah Berguna

Cheat sheet perintah terminal Zeline yang paling sering dipakai sehari-hari. Klik tombol salin di tiap kartu untuk menyalinnya.

zeline

Membuka interactive CLI Zeline.

zeline doctor

Memeriksa konfigurasi dan dependensi.

zeline gateway status

Memeriksa status gateway.

zeline gateway log

Melihat log gateway.

zeline update

Memperbarui Zeline ke versi terbaru.

zeline tools list

Menampilkan daftar tools yang tersedia.

Catatan Penting

  • Zeline membutuhkan koneksi internet saat memakai model AI berbasis cloud.
  • Termux dan proses gateway harus tetap berjalan agar bot dapat merespons. Android bisa menghentikan proses di latar belakang karena penghematan baterai.
  • 9Router bukan syarat wajib untuk menggunakan Zeline.
  • Penggunaan API bisa memiliki biaya atau batas kuota tergantung provider.
  • Jangan membagikan API key, token Telegram, atau password dashboard.
  • Untuk penggunaan 24/7 yang lebih stabil, disarankan menggunakan VPS.
