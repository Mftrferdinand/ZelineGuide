# Zeline — Installation Guide

Panduan instalasi Zeline Framework (Agentic AI by Zerolinear) dalam Bahasa Indonesia —
dari install Termux di Android sampai bot Telegram pertama berjalan.

**Live:** https://mftrferdinand.github.io/ZelineGuide/

## Isi

- 6 langkah instalasi: Termux → Install Zeline → 9Router → Model AI → Telegram → Perintah berguna
- Semua perintah siap salin (tombol copy built-in)
- Dukungan 4 platform: Android (Termux), Linux, macOS, Windows

## Struktur

```
index.html   # halaman guide (single-file, self-contained)
```

Halaman ini statis dan mandiri — tanpa build step. Font diambil dari Google Fonts CDN.

## Deploy

Dilayani oleh **GitHub Pages** dari branch `main`, root `/`.
Setiap push ke `main` otomatis ter-deploy ulang.
